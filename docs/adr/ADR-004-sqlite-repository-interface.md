# ADR-004: SQLite + Repository interface (смяна по-късно)

- **Status:** Accepted
- **Дата:** 2026-10-12

## Контекст
Нужна е персистентност с ниска операционна сложност. Алтернативи: PostgreSQL/MySQL
(външен сървър, неподходящ за add-on), файлова/JSON (няма транзакции и заявки).

## Решение
`node:sqlite` (SQLite, WAL режим) като имплементация зад Repository интерфейс.
Интерфейсът е стабилен; двигателят може да се смени по-късно без промяна на ядрото.

## Последици
- Плюс: транзакции, индекси, един файл, лесно backup/restore.
- Минус: един процес-писател (WAL ограничение) — приемливо за add-on.
