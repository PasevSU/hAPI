Shared settings file

The gateway keeps the same six keys in psemp-gateway/settings.default.json. Import it here so both halves agree on version, framework, organization and PGP fingerprint, and export the current values back to that file when you change them.

origin is not copied from the file: it names the producer, so the extension always writes Thunderbird and the gateway writes PSEMP-Gateway. That is the only intentional difference between the two, and the parity test asserts it.

OpenPGP already configured in Thunderbird. Put the fingerprint of the key your account already signs with here (Account Settings → End-to-End Encryption → OpenPGP Key Manager → your key). A MailExtension cannot read Thunderbird's keyring, so this header is a claim: the headers are added outside the signed MIME part and are not covered by Thunderbird's signature. psemp-gateway pgp-check compares the claim with the signer actually present in the delivered message, and it never adds a second signature to a message Thunderbird already signed. Bear in mind that with encryption switched on the X-PasevSU-* headers stay in the clear while the body does not.

Real OpenPGP signatures (.asc) and OpenTimestamps (.ots) cannot be produced inside a Thunderbird MailExtension; the X-PasevSU-OTS header is a marker for the SMTP gateway. The marker is written by default so no message is ever sent unstamped — untick the box only if you deliberately do not want the gateway to stamp.
