Shared settings file

The gateway keeps the same keys in psemp-gateway/settings.default.json. Import it here so both halves agree on version, framework, organization and PGP fingerprint, and export the current values back to that file when you change them.

origin is not copied from the file: it names the producer, so the extension always writes Thunderbird and the gateway writes PSEMP-Gateway.

The delivery receipt is a standard MDN (RFC 8098): the recipient is asked, not required, and most clients show a dialog.

OpenPGP already configured in Thunderbird. Put the fingerprint of the key your account already signs with here.

„Signatur-Ablaufdatum: Kein Zeitpunkt in der Signatur enthalten“ is a fact, not a fault. Thunderbird's OpenPGP dialog shows it when the signature carries no expiry date.

Real OpenPGP signatures (.asc) and OpenTimestamps (.ots) cannot be produced inside a Thunderbird MailExtension.
