Изводът от числата: **няма мъртъв код по смисъла „изнесено и неизползвано“**. Това, което

Затова „премахване“ тук значи две неща: да се махне ДУБЛИРАНА логика и да се запишат
условията, при които шимовете падат.

## 3. Остарели функции — какво стои и при какво условие пада

| Остаряло | Къде | Защо още е там | Кога пада |
| --- | --- | --- | --- |
| API v1 (legacy) до v2 | `api-version.js` | външни клиенти на v1 още работят | при мажорна версия + `SUNSET` |
| `/qr` без разширение → 301 | `server.js` | стари разпечатани кодове | след обявен срок, не по-рано от мажор |
| `X-File-Key` (legacy ключ на файл) | `gateway-api.js` | издадени ключове `fk_…` | след изтичане на всички издадени |
| `STORAGE_LEGACY_LOCATION` | `storage-preflight.js` | миграция от старо място на данни | след една миграционна вълна |
| `legacyCopy` (копиране без Clipboard API) | `ui/export-center.js` | порталът се отваря и по HTTP | когато HTTP бъде забранен |
| `migration-bridge.js` | цял модул | пренася legacy метаданни към core store | след приключване на миграциите |
| JSON копие до SQLite | `sqlite-store.js` | архив за връщане назад | след мажор + доказана стабилност |
| Legacy alias на публичния gateway | `build-haoss.cjs` (документиран) | външни адреси | по същия график като v1 |

Правилото, което следвам: **съвместимост не се трие, докато някой може да я ползва** — иначе
„почистването“ чупи жив адрес. Затова тези редове стоят, но с изписана причина и с условие.

## 4. Какво е премахнато сега

- **Дублиран построител на QR.** Параметрите (клетка 8, поле 4, мащабируем SVG) стояха на две
  места: в `server.js` за `/qr.svg` и в `routes/portal-tokens.js` за кода на адреса с токен.
  Сега има един модул — `hapi_enterprise/qr-svg.js`; и двете места го викат, а
  `tests/portal-tokens.cjs` иска `qrSvg` да съвпада байт по байт с него.
- **Дублиран сървърен клон за регистрация** (от предишния комит `cef644e`): нов маршрут
  засенчи съществуващия и свали 8 теста; премахнат е, панелът минава през стария договор.

## 5. Какво НЕ се пипа

- Нормативните документи (`02_TO_BE_ARCHITECTURE`, ADR) не се пренаписват, за да паснат на
  кода — разминаване се записва в матрицата.
- Отворените дефекти не се „затварят с текст“: DEF-06 (WORM) иска среда, DEF-49 иска превод.
- Compatibility шимовете от §3 не се трият без решение за версия — те са жив договор с
  външни адреси и издадени ключове.
