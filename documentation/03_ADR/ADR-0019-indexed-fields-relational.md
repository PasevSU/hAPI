# ADR-0019: `indexed:true` полета се държат и релационно

- **Status:** Accepted
- **Дата:** 2026-10-12

## Контекст
Търсенето по поле (§8.6) изисква бърз достъп до стойностите на полетата, не само
съхранение в blob.

## Решение
`indexed:true` полетата се записват в релационните `value_text`/`value_number` колони
и имат индекс (`idx_variables_value_text`, `idx_variables_field`), което позволява
`search()` по префикс и подниз без пълно сканиране на blobs.

## Последици
- Плюс: бързо търсене по индексирани полета.
- Минус: шифрованите полета не се търсят (изключени от `search()` по дизайн).
