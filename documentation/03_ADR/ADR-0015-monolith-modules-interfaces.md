# ADR-0015: Монолит с модули + интерфейси (без microservices)

- **Status:** Accepted
- **Дата:** 2026-10-12

## Контекст
Add-on се изпълнява в Home Assistant (ограничени ресурси, един процес).
Microservices внасят мрежова сложност без полза на този мащаб.

## Решение
Монолитен процес, организиран в модули, свързани през интерфейси/фабрики
(`create(...)`) и Dependency Injection (контейнер, Фаза 2.1). Няма microservices.

## Последици
- Плюс: прост deployment, по-малко операционни рискове, лесни тестове.
- Минус: по-трудно хоризонтално мащабиране (не е цел на add-on-а).
