# ADR Index

Single authoritative ADR registry for hAPI Enterprise.

- `0001–0012` — enterprise governance, security, and release decisions.
- `0013–0023` — implementation-level decisions for Phases 1–4 (merged from the former `docs/adr/` tree).
- `0024` — consolidation of every idea into one project (v6.0 canonical plan).
- `0025` — Report Studio: manifest-driven reports with an RFC 3161 scope (partially
  supersedes ADR-0023's exclusion of the document generator).
- `0026` — Public API Gateway + File Delivery & Download Access Control: two isolated
  channels (admin Ingress vs public gateway), central most-restrictive-wins policies,
  SHA-256 verified transfer and evidence packages.
