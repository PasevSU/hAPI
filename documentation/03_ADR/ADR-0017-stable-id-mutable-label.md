# ADR-0017: `id_gruppe` стабилен, `name_folder` mutable label

- **Status:** Accepted
- **Дата:** 2026-10-12

## Контекст
Историческият ключ на variable `{prefix}-{ID_db}-{name_folder}-{field}` използваше
името на папката. Преименуване на папка променяше ключовете (и губеше данни/връзки).

## Решение
Композитният ключ използва стабилен `id_gruppe` (хекс ID на групата), а
`name_folder`/`name` е mutable label само за показване. Преименуването не променя ключа.

## Последици
- Плюс: преименуването е безопасно; връзките оцеляват.
- Минус: ключовете не са четливи (компенсира се с индекси и metadata).
