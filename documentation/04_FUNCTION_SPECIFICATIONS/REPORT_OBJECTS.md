# Report Studio — обектна библиотека (договор)

Обектите, които се добавят в отчета. Регистърът е един: `hapi_enterprise/ui/report-objects.js`.
Един и същ списък важи за интерфейса и за валидатора (`hapi_enterprise/report-manifest.js`),
така че „готов“ обект не може да съществува само в менюто.

| Статус    | Значение                                                                     |
| --------- | ---------------------------------------------------------------------------- |
| `ready`   | добавя се и минава валидация; рендира се в PDF                                |
| `system`  | `rfc3161-start` / `rfc3161-stop` — винаги първи/последен, заключени (ADR-0025) |
| `planned` | вижда се в библиотеката, но е изключен и надписан „v2“ — без фиктивни функции |

## Готови обекти

| Тип          | Категория    | Съдържание                                            | В PDF                          |
| ------------ | ------------ | ----------------------------------------------------- | ------------------------------ |
| `title`      | Текст        | `value`, `subtitle`                                   | `h1` + абзац + линия           |
| `subtitle`   | Текст        | `value` (заглавие на раздел)                          | `h2`                           |
| `text`       | Текст        | `value`                                               | `p` (с етикет `h3` отгоре)     |
| `legal`      | Правни       | `value`; празно → стандартната декларация             | `h3` + `p`                     |
| `metadata`   | Данни        | `items[{key,value}]`                                  | таблица „Поле/Стойност“        |
| `data-block` | Данни        | — (стойностите ги дава сървърът)                       | таблица „Показател/Стойност“   |
| `table`      | Таблици      | `source` (`records:…`) + `columns[]`                  | таблица с празни клетки        |
| `hash-table` | Таблици      | `algorithms[]` (CRC32, MD5, SHA1, SHA256, SHA512)     | таблица с реални хешове        |
| `image`      | Медия        | `data`/`dataUrl` (JPEG)                               | изображение                    |
| `qr`         | Медия        | `value`                                               | векторен QR + текста под него  |
| `signature`  | Сертификати  | —                                                     | „не е издаден“ без ключ        |
| `separator`  | Оформление   | —                                                     | линия                          |
| `pagebreak`  | Оформление   | —                                                     | нова страница                  |

## Планирани (v2)

`logo`, `certificate`, `columns`, `dynamic`. Показани са, но са изключени —
`planned()` в регистъра и `tests/report-objects.cjs` пазят точно това: планиран тип **не** е в
`ELEMENT_TYPES`, тоест не може да влезе в манифест по погрешка.

## Инварианти

- **INV-O1 — Един източник.** Всеки `ready` обект е в `ELEMENT_TYPES`; всеки `planned` — не е.
  Проверява се от `tests/report-objects.cjs`.
- **INV-O2 — Без фиктивни функции.** Обектът или се рендира, или е изключен с надпис „v2“.
- **INV-O3 — Празното поле не се губи.** `legal` без собствен текст печата стандартната
  декларация (не празен блок); `pagebreak` добавя ТОЧНО един лист — мери се спрямо същия
  манифест без прекъсването (`tests/report-render.cjs`).
- **INV-O4 — Структурата е истинска.** `subtitle` се рендира като `h2`, а не като уголемен
  параграф — така и програмите, които четат PDF, виждат разделите.
- **INV-O5 — Никакви измислени стойности.** `data-block` печата само това, което сървърът
  подаде (`reportSystemInfo` в `server.js`); липсваща стойност е „—“, а не измислена версия.
  Абсолютните пътища не влизат в отчета — само относителното име на базата.

## Къде се променя

1. `ui/report-objects.js` — статус и подразбиращи се стойности.
2. `report-manifest.js` — `ELEMENT_TYPES` (и специфична валидация, ако има).
3. `report-render.js` — как блокът влиза в PDF.
4. `ui/report-studio.js` — полета в свойствата и ред в A4 прегледа (`ui/styles.css` за стил).
5. Тестове: `tests/report-objects.cjs`, `tests/report-render.cjs`.
