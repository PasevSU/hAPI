# Module Specifications

Each module gets a `FUNCTION_SPECIFICATION_TEMPLATE.md`-formatted spec here, one
file per module. Key modules to spec first:

- `registry.md` — profile/field/type registry
- `signer.md` — receipt signing / verification
- `file-crypto.md` — encryption at rest
- `audit-chain.md` — hash-chained audit
- `portal.md` — QR landing + verify
- `storage-migrate.md` — zero-damage migration

Specs are written as functions reach Phase 5–7 design freeze.
