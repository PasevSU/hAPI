# Вход през външен доставчик (Pocket ID / Keycloak) — ръководство

От 0.69.86 hAPI може да влиза през OIDC доставчик. Локалните акаунти остават — това е
допълнителен вход, не подмяна.

## 1. Какво ти трябва

- Работещ доставчик (в твоя случай add-on-ът **Pocket ID**), достъпен по HTTPS.
- Адресът, по който hAPI е достъпен за браузъра (напр. `https://pasev.asuscomm.com`).

## 2. Регистрация при доставчика

1. Pocket ID → **OIDC Clients** → **New client**.
2. Име: `hAPI`.
3. **Callback URL**: `https://<адрес-на-hAPI>/api/v1/auth/oidc/callback`
   (точно този път; без наклонена черта накрая).
4. Ако клиентът е поверителен — копирай **Client Secret**.
5. Създай група (напр. `hapi-admins`) и добави в нея хората, които трябва да управляват.

## 3. Настройки на add-on-а

Добавят се като променливи на средата на add-on-а (не в `config.yaml`):

```
HAPI_OIDC_ISSUER=https://<адрес-на-pocket-id>
HAPI_OIDC_CLIENT_ID=<от Pocket ID>
HAPI_OIDC_CLIENT_SECRET=<само ако клиентът е поверителен>
HAPI_OIDC_REDIRECT_URL=https://<адрес-на-hAPI>/api/v1/auth/oidc/callback
HAPI_OIDC_ADMIN_GROUP=hapi-admins
HAPI_OIDC_AUTO_PROVISION=1
```

- Без `ADMIN_GROUP` влизането е **само за четене** (роля `viewer`).
- `AUTO_PROVISION=1` създава локален акаунт при първи вход; без него първо трябва да има
  акаунт със същото потребителско име (от `preferred_username` или `email`).
- Ако искаш само определени групи: `HAPI_OIDC_ALLOWED_GROUPS=група1,група2`.

## 4. Проверка

1. Отвори `https://<адрес-на-hAPI>/api/v1/auth/oidc/login` в браузър.
2. Доставчикът иска вход → връща те обратно → отваря се панелът.
3. Ако видиш `404` — OIDC не е конфигуриран (липсва някоя от трите задължителни променливи).
4. Ако видиш `403` — акаунтът не е в разрешена група (или няма локален акаунт при
   `AUTO_PROVISION` изключено).

## 5. Чести грешки

| Симптом | Причина |
| --- | --- |
| Доставчикът връща „invalid redirect_uri“ | `HAPI_OIDC_REDIRECT_URL` не съвпада точно с регистрирания адрес (вкл. схема и порт) |
| Пренасочва към вътрешен адрес | `APP_URL` на Pocket ID е LAN адрес — трябва да е адресът, по който браузърът го вижда |
| `400 Unknown or expired login state` | входът е стоял отворен над 5 минути или е повторен — започни отново |
| Влиза, но панелът е само за четене | липсва `HAPI_OIDC_ADMIN_GROUP` или потребителят не е в нея |

## 6. Изход

Изходът от hAPI е `/api/v1/auth/logout`. Изходът от самия доставчик (single logout) още не
е свързан — ако затвориш сесията там, hAPI сесията остава до изтичане.
