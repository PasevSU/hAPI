# Промени в hAPI Enterprise

Тази версия: **0.69.135**. Пълната история е в [CHANGELOG.md](https://github.com/PasevSU/hAPI/blob/main/CHANGELOG.md).

## 0.69.135

- **Шестдесети сценарий: хранилището се управлява изцяло през панела.** J62 прикача файл с
  бутона „Прикачи файл“ (изборът на файл минава през същия input, който браузърът отваря),
  качва втори файл В папка през бутона на самата папка, иска пакет за папката (и проверява, че
  в заявката отива НЕЙНИЯТ път) и накрая я изтрива през менюто ⚙ — с второто потвърждение,
  което панелът иска, когато add-on-ът отговори 409 за непразна папка.
- **Съобщенията на панела вече се чакат с точния им текст.** Създаването на портал се чака по
  „Порталът е създаден“, а пакетът — по самото изтегляне: преди това дошло по-късно
  съобщение от предишен сценарий можеше да мине за отговор на следващия (и го направи).
- Пазачът на GUI-тестовете вдига прага на 59 сценария (сега 60).
- Регистърът е пре-печатан за 0.69.135; changelog, add-on changelog, API справочник, инвентар,
  одитни събития, индекс на документацията, кодове за грешка, admin OpenAPI, матрица на
  тестовете и проверките на изданието са генерирани наново от кода.
